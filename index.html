Unlocking Korean Verbs: A User-Friendly Exploration into the Verb Lexicon

A web interface and Python library (pySejongFrame) for the subcategorization frames of the Sejong verb dictionary

Abstract

The Sejong dictionary dataset offers a valuable resource, providing extensive coverage of morphology, syntax, and semantic representation. This dataset can be utilized to explore linguistic information in greater depth. The labeled linguistic structures within this dataset form the basis for uncovering relationships between words and phrases and their associations with target verbs. This paper introduces a user-friendly web interface designed for the collection and consolidation of verb-related information, with a particular focus on subcategorization frames. Additionally, it outlines our efforts in mapping this information by aligning subcategorization frames with corresponding illustrative sentence examples. Furthermore, we provide a Python library that would simplify syntactic parsing and semantic role labeling. These tools are intended to assist individuals interested in harnessing the Sejong dictionary dataset to develop applications for Korean language processing.

System

The Sejong dictionary, built in the 21st Century Sejong Project, stores each Korean verb as an XML file with morphology, senses (semantic class and English translation), subcategorization frames, selectional restrictions with semantic roles such as AGENT (AGT) and THEME (THM), and example sentences. The paper turns this resource into two tools:

  1. Web interface. Verbs are listed in Korean alphabetical order and can be searched by verb, frame, argument, morphological inflection, and semantic group. Each word page renders the XML tags (orthography, morphology, senses, frames, selectional restrictions, examples) for users without programming experience.
  2. Frame-to-sentence projection. Argument boundaries in each example sentence are found by heuristic chunking at postpositions, which in Korean usually mark the end of arguments and modifiers, with dependency structures as a fallback. The postposition of each chunk is compared with the postpositions in the frame (e.g. -이, -을) to decide whether it is an argument, and the frame's semantic roles are assigned to it.
  3. Python library (pySejongFrame). A corpus reader for the Sejong Frame Dictionary with direct loading, lazy loading (indexing postponed until the data is queried), and NLTK integration, plus queries for entries (e.g. entries("수정하다.vv")), senses, semantic classes, translations, frames, and arguments.

Resource Overview

  • Coverage. The Sejong dictionary describes 15,181 verbs with 1.812 subcategorization frames per verb on average, far more verbs than Korean PropBank (2,749 verbs, 1.408 frames) or the NIKL SRL lexicon (3,660 verbs, 1.593 frames).
  • Contribution. A corpus of Sejong dictionary example sentences annotated with argument–predicate boundaries, plus a web interface and a Python library for accessing the dictionary.
  • Distribution. The National Institute of Korean Language, which holds the Sejong Project copyright, granted permission to distribute these derivative materials and will host the web system; the dictionary files for the library must still be obtained from the institute.
  • Uses. Lexicalized parsing, semantic role labeling, and FrameNet parsing for Korean, and a planned Korean VerbNet that harmonizes Sejong, PropBank, and FrameNet frames.
